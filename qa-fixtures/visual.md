# Downleaf — 为长文档而生

一个极简、快速、完全属于你的 Mac Markdown 编辑器。打开文件就开始写，不需要导入知识库，也没有账号、同步或格式绑架。

这款编辑器把正文放在视觉中心，并用右侧快速大纲解决长文档里的定位问题。低频功能全部进入 macOS 菜单栏，让窗口始终安静。

> 核心承诺：打开即写、长文档依然流畅、文件永远属于用户。

## 01 设计目标

Downleaf 不试图成为另一个复杂的知识管理系统。它只专注于把编辑、阅读和文档导航做到足够安静、可靠和高效。

### 打开即写

双击任意 Markdown 文件后，焦点直接落在正文。新建文稿先留在本地缓冲区，直到用户明确选择保存位置。

### 文件始终属于用户

所有内容都是普通的 Markdown 文件，可以继续由 Finder、Git、终端和其他编辑器共同使用。

## 02 编辑体验

编辑器使用原生文本系统，中文输入、选择、撤销、查找、拼写检查和系统文本服务都保持 Mac 应有的手感。

### 键盘优先

常用动作都有快捷键，并可通过命令面板快速发现。

### 中文输入与长文档

语法高亮与大纲解析异步进行，不阻塞正在发生的输入。

## 03 快速大纲

右侧大纲从 H1 到 H6 自动生成，支持层级折叠、当前章节跟随和完整键盘导航。

### 拖拽调整宽度

直接拖动分隔线即可改变大纲宽度，双击恢复默认尺寸，拖到最窄则自动收起。

### 当前章节自动跟随

编辑光标移动时，大纲会高亮当前章节并保持对应条目可见。

## 04 三种阅读方式

在源码编辑、左右分栏和纯阅读之间切换，不改变文件内容，也不会丢失上下文。

### 源码编辑

保留 Markdown 语法的透明与稳定。

### 左右分屏

一边编辑，一边查看排版结果。

### 纯阅读

用舒适的行宽和层级阅读长文档。

## 05 文件生命周期

已有路径的文件按原位置保存；未命名文稿只生成本地恢复副本，不会被静默放到陌生目录。

### 自动保存

默认开启。命名文件在输入短暂停顿后写回磁盘。

### 安全关闭

关闭未保存内容时，明确提供保存、不保存和取消。

## 06 本地优先

没有账号系统、云端数据库、遥测或后台上传。
